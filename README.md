# The Cortex Exchange

Website for The Cortex Exchange, a trading education and mentorship community.

A single static page (`index.html`) with a 3D version of the logo in the hero section. There is no build step.

## Deploying on Render

1. Create a new **Static Site** on Render and connect this repository.
2. Leave the build command empty.
3. Set the publish directory to `.`
4. Click **Create Static Site**.
